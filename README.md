# ClipLite · 轻量美观剪切板

Windows 剪贴板管理器：托盘常驻 + 全局热键呼出深色毛玻璃面板，单击复制、双击粘贴，键盘流一键回车粘贴。

- **轻量**：Tauri 2 构建，安装包约 10MB，内存占用约 40-60MB
- **美观**：自绘毛玻璃（截屏 + 高斯模糊），透出强度可调，呼吸感动效
- **快捷**：`Ctrl+Shift+V` 呼出 → 自动选中第一条 → 回车直接粘贴回原窗口

## 功能

- 文本 / 图片剪贴板历史（SQLite 持久化，默认 500 条自动清理，置顶保留）
- 全局热键呼出（默认 `Ctrl+Shift+V`，设置中可重录），面板出现在光标旁
- 键盘流：↑↓ 选择、回车粘贴、Esc 关闭；单击复制、双击粘贴
- 模糊搜索 + 关键词高亮；星标置顶；右键删除
- 毛玻璃透出强度滑动条（实时预览）
- 开机自启、退出时清空（隐私开关）
- 防回环（自身写入不重复记录）、内容去重、超 10MB 图片跳过

## 安装

下载 release 的 `ClipLite_x.x.x_x64-setup.exe`，双击安装即可（无需额外运行库，Win10 1809+ / Win11）。

## 开发

```bash
npm install
npm run tauri dev    # 开发模式
npm run tauri build  # 打包（NSIS 安装包）
```

要求：Node 18+、Rust（MSVC 工具链 + Windows SDK）。

## 快捷键

| 按键 | 行为 |
|---|---|
| `Ctrl+Shift+V` | 呼出 / 收起面板 |
| `↑` / `↓` | 在历史中移动选中 |
| `Enter` | 复制并粘贴选中项到原窗口 |
| `Esc` | 收起面板（焦点归还原窗口） |
| 单击条目 | 复制到剪贴板 |
| 双击条目 | 复制并自动粘贴 |
